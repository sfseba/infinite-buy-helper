# 무한매수 도우미

라오어의 무한매수법을 **직접 주문하는 사람**을 위한 도우미입니다.

- **웹 계산기**: 오늘 넣을 LOC 주문을 계산하고, 체결을 입력하면 T·평단·잔금이 자동으로 바뀌어요.
- **알림 봇**: 매일 아침 오늘의 주문을 텔레그램으로 보내줘요.

> ⚠️ 이 도구는 **주문을 넣지 않습니다.** 계산하고 알려주기만 해요. 주문은 증권사 앱에서 직접 넣으세요.
> 레버리지 ETF는 큰 손실이 날 수 있어요. 투자 판단과 결과에 대한 책임은 사용자에게 있습니다.

---

## 무엇을 할 수 있나요

| 기능 | 설명 |
|---|---|
| 오늘의 주문표 | 1회 매수금, 별%, 별지점과 매수·매도 주문(가격, 수량)을 계산해요 |
| 체결 입력 → 장부 자동 갱신 | 종가·고가를 넣으면 체결 여부를 추정하고, 반영 전에 바뀔 값을 미리 보여줘요 |
| 소액 보정 | 절반 금액으로 1주를 못 사면 한 건으로 모아 주문하고, 그 사실을 알려줘요 |
| 사이클 기록 | 목표가 매도가 체결되면 사이클 수익과 수익률이 쌓여요 |
| 잔고 대조 | 증권사 잔고와 장부가 다르면 경고하고, 증권사 값으로 맞출 수 있어요 |
| 텔레그램 알림 | 매일 체결 추정 결과와 오늘의 주문을 보내요. 금요일 장 다음 날엔 잔고 대조를 알려줘요 |
| 실패 알림 | 시세를 못 가져오거나 봇이 멈추면 텔레그램으로 바로 알려줘요 |
| 여러 포지션 | TQQQ와 SOXL을 따로 운영할 수 있어요 |

지원: TQQQ, SOXL / 20·30·40분할 / V4.0 일반모드.
소진 구간(리버스모드)은 계산하지 않고 경고만 해요.

## 시작하기

### 1. 저장소 만들기

1. 이 저장소를 **Fork** 하거나, 파일 전체를 새 저장소에 올리세요.
2. 투자 기록이 담기므로 **Private 저장소**를 추천해요. (Private 저장소에서 GitHub Pages를 쓰려면 유료 플랜이 필요할 수 있어요. 그럴 땐 웹 계산기만 Public 저장소로 따로 배포해도 돼요.)

### 2. 웹 계산기 켜기 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main / (root)** → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`에서 열려요.

내 컴퓨터에서 열어보려면 저장소 폴더에서 `npx serve .` 또는 `python3 -m http.server`를 실행하세요. (`index.html`을 더블클릭하면 브라우저 보안 정책 때문에 동작하지 않아요.)

### 3. 텔레그램 알림 켜기 (선택)

1. 텔레그램에서 `@BotFather` → `/newbot` → 봇 이름과 아이디(끝이 `bot`) 입력 → **토큰** 복사
2. 만든 봇과 대화방을 열고 **/start** 누르기
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열고 `"chat":{"id":숫자}`의 숫자 복사
4. 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - `TELEGRAM_BOT_TOKEN` = 토큰
   - `TELEGRAM_CHAT_ID` = 숫자
5. 웹 계산기에서 포지션을 만들고 **설정 · 백업 → JSON 복사** → 저장소의 `data/state.json`에 붙여넣고 커밋
6. **Actions → 오늘의 주문 알림 → Run workflow**로 한 번 실행해 메시지가 오는지 확인

이후에는 **월~금 23:07 UTC(한국 시간 화~토 오전 8시쯤)**에 자동으로 실행돼요. GitHub 사정으로 몇십 분 늦게 올 수 있어요.

## 매일 쓰는 방법

### 봇을 쓰는 경우 (추천)

1. 아침에 텔레그램 메시지를 받아요.
2. 메시지의 주문을 그대로 증권사 앱에 **예약주문**으로 넣어요.
3. 끝. 봇이 다음 날 종가로 체결을 추정해서 장부(`data/state.json`)를 자동으로 고쳐요.

주말에 한 번, 증권사 잔고와 장부를 대조하세요. 다르면 웹 계산기에서 **봇 장부 불러오기 → 직접 수정 또는 잔고 대조 → JSON 복사** 후 `data/state.json`에 붙여넣고 커밋하면 돼요.

### 웹 계산기만 쓰는 경우

1. **체결 입력**에 지난 거래일의 종가·고가를 넣고 **체결 추정**을 눌러요.
2. 증권사 체결 내역과 비교해서 다르면 체크, 수량, 체결가를 고쳐요.
3. **장부에 반영** → 새로 계산된 **오늘의 주문**을 앱에 넣어요.

장부는 브라우저에만 저장되니 가끔 **JSON 저장**으로 백업하세요.

> 봇과 웹 계산기에서 **동시에 장부를 고치면 서로 달라져요.** 봇을 쓴다면 봇 장부(`data/state.json`)를 기준으로 삼으세요.

## 체결 추정 방식

| 주문 | 체결 조건 | 체결가 |
|---|---|---|
| LOC 매수 | 종가 ≤ 주문가 | 종가 |
| LOC 매도 | 종가 ≥ 주문가 | 종가 |
| 지정가 매도 | 고가 ≥ 주문가 | 주문가 |

실제로는 주문을 안 넣었거나, 부분 체결되거나, 증권사가 주문을 거부할 수 있어요. **추정은 추정일 뿐이에요.** 그래서 잔고 대조가 필요해요.

## 규칙 안내

계산은 인터넷에 공개된 **무한매수법 V4.0 일반모드 요약**을 바탕으로 해요.

- 1회 매수금 = 남은 현금 ÷ (분할 수 − T)
- 별지점 = 평단 × (1 + 별%)
- 목표 수익률: TQQQ +15%, SOXL +20%

라오어님은 규칙과 시트를 무단으로 재배포하지 말아 달라고 안내하고 있어요. 그래서 이 저장소는 자세한 규칙을 설명하지 않아요. **정확한 공식 규칙은 [라오어 무한매수법 카페](https://cafe.naver.com/infinitebuying)와 책에서 직접 확인하세요.** 규칙이 바뀌면 이 도구의 계산이 틀릴 수 있어요.

## 폴더 구조

```
index.html, app.js, style.css   웹 계산기 (GitHub Pages)
engine/engine.mjs               계산 엔진 (웹과 봇이 같이 씀, 외부 라이브러리 없음)
bot/daily.mjs                   알림 봇 진입점
bot/market.mjs                  시세 가져오기 (Yahoo → 실패 시 Stooq)
bot/telegram.mjs, format.mjs    텔레그램 전송, 메시지 문구
data/state.json                 봇 장부
test/                           테스트 (node --test)
.github/workflows/daily.yml     매일 실행
.github/workflows/test.yml      코드가 바뀌면 테스트
```

개발: Node 20 이상, 설치할 패키지 없음.

```bash
npm test                 # 테스트
node bot/daily.mjs --dry # 저장·전송 없이 오늘 메시지만 출력 (인터넷 필요)
```

## 하지 않는 것

- **자동 주문**: 법적 문제(투자일임 등)와 API 키 보안 부담 때문에 넣지 않았어요.
- **증권사 화면 매크로**: 증권사 화면이 바뀌면 조용히 고장 나서 넣지 않았어요.
- **리버스모드 계산**: 규칙이 복잡하고 자료마다 달라서 경고만 해요.

## 면책

이 프로젝트는 개인 학습용 도구이며 투자 권유가 아닙니다. 계산 오류, 시세 오류, 규칙 해석 차이로 손실이 날 수 있어요. 사용에 따른 모든 결과는 사용자에게 있습니다.
